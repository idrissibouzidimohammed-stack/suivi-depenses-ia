# \# ?? Suivi de Dépenses Personnelles avec IA

# 

# Application web fullstack de gestion budgétaire personnelle avec conseils automatiques générés par IA.

# 

# \## ?? Technologies utilisées

# 

# \### Backend

# \- Java 17 + Spring Boot 4

# \- Spring Data JPA + Hibernate

# \- Spring Security + JWT

# \- MySQL 8

# \- API Groq (LLaMA 3)

# 

# \### Frontend

# \- React 18 + Vite

# \- React Router DOM

# \- Axios

# \- Recharts (graphiques)

# 

# \## ? Fonctionnalités

# 

# \- ? Inscription et connexion sécurisée (JWT)

# \- ? Ajout, modification, suppression de dépenses

# \- ? Tableau de bord avec graphiques interactifs

# \- ? Graphique par catégorie (barres)

# \- ? Graphique tendances mensuelles (ligne)

# \- ? Conseils budgétaires générés par IA (Groq)

# 

# \## ??? Installation

# 

# \### Prérequis

# \- Java 17+

# \- Node.js 18+

# \- MySQL 8+

# 

# \### Backend

# 

# ```bash

# cd backend

# \# Configurer application.properties avec vos credentials MySQL et clé Groq

# ./mvnw spring-boot:run

# ```

# 

# \### Frontend

# 

# ```bash

# cd frontend

# npm install

# npm run dev

# ```

# 

# \## ?? Utilisation

# 

# 1\. Ouvrir http://localhost:5173

# 2\. Créer un compte

# 3\. Ajouter des dépenses

# 4\. Consulter le tableau de bord

# 5\. Obtenir des conseils IA
